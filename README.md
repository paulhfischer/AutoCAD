# AutoCAD

## Setup

Use `APPLOAD` in AutoCAD to load `count_blocks.lsp`, `convert_lines.lsp` and `door.lsp`.

## Commands

- `COUNT_BLOCKS`: count selected block references by their stored block name.
- `CONVERT_LINES`: convert selected lines to polylines, restoring `PEDITACCEPT` afterward.
- `DOOR`: select circular arcs near an endpoint to draw door lines in the current UCS; Enter finishes. Frame extensions are 0.4 drawing units.
